# 三国杀 · 群雄逐鹿

一个原创实现的类三国杀卡牌对战网页游戏。单页应用，纯 HTML/CSS/JS，无任何外部依赖与网络请求，双击 `index.html` 或用任意静态服务器打开即可游玩。

**🎮 在线游玩**：https://caiqing.github.io/sanguo-kill/ （GitHub Pages，加载约 4MB 插画资源后即可完整体验）

## 玩法概览

经典的 5 人身份局：**1 主公 · 1 忠臣 · 2 反贼 · 1 内奸**。

- 开场先选武将（10 名各带绝技的名将），再抽定身份——只有你自己的身份可见
- 按身份触发不同的剧情旁白与胜利条件：
  - 主公/忠臣：诛灭所有反贼与内奸
  - 反贼：斩杀主公
  - 内奸：笑到最后，与主公单挑夺天下
- 主公先手，回合流程为 判定 → 摸牌 → 出牌 → 弃牌；手牌上限等于当前体力

## 武将（10 名，各带技能）

| 武将 | 技能 | 效果 |
|------|------|------|
| 刘备 | 仁德 | 出牌阶段将手牌交给他人，给出两张以上回复体力 |
| 关羽 | 武圣 | 红色手牌可当【杀】使用或打出 |
| 张飞 | 咆哮 | 出牌阶段【杀】无次数限制 |
| 诸葛亮 | 空城 | 没有手牌时不能被【杀】和【决斗】指定 |
| 赵云 | 龙胆 | 【杀】当【闪】、【闪】当【杀】 |
| 曹操 | 奸雄 | 受伤后可获得造成伤害的牌 |
| 孙权 | 制衡 | 弃任意手牌摸等量的牌 |
| 吕布 | 无双 | 你的【杀】需两张【闪】抵消，决斗需两张【杀】 |
| 貂蝉 | 离间 | 弃一张牌令两名男性角色决斗 |
| 华佗 | 急救 | 回合外红色牌可当【桃】自救 |

主公额外 +1 体力上限。

## 卡牌（89 张一副）

- **基本牌**：杀、闪、桃、酒（酒杀 +1 伤害 / 濒死自救）
- **锦囊**：无中生有、过河拆桥、顺手牵羊、决斗、南蛮入侵、万箭齐发、桃园结义、五谷丰登、无懈可击
- **延时锦囊**：乐不思蜀、闪电（判定黑桃劈 3 点雷电伤害，否则移交下家）
- **装备**：诸葛连弩（无限杀）、青龙偃月刀（被闪后可追杀）、贯石斧（弃两张牌强行命中）、八卦阵（判定红色视为闪）、进攻马 / 防御马

## 战斗与互动

- 每张卡牌都有飞行动画与命中特效：刀光、格挡护盾、雷电、箭雨、火焰、粒子迸溅、伤害数字、屏幕震动
- 书法大字弹出（杀！闪！决斗！酒杀！），死亡时头像灰化翻出身份
- Web Audio 实时合成音效（无需音频文件），右上角可静音
- AI 对手具备身份推理：攻击主公者会被全场标记"反贼相"，斩杀反贼者彰显忠义，记仇账本影响 AI 敌意

## 操作

1. 点击【入 局】→ 选择武将与身份（或随机）→ 观看身份剧情
2. 出牌阶段：点击一张手牌 → 点击目标角色头像（高亮可选）→ 点击【出 牌】
3. 再次点击已选中的手牌可切换用法（如关羽的红牌：视为【杀】）
4. 技能按钮在出牌阶段可用时点亮；被【杀】指定时会弹出响应面板要【闪】
5. 阵亡后自动进入观战加速模式

## 录像与回放

每局自动录制（事件流 + 逐事件全局面快照）。对局结束后：

- 结算页点击 **▶ 观看本局回放**，逐帧重演：卡牌插画、座位状态、解说字幕、战报与音效同步还原
- 回放控制条支持播放/暂停、前后快进 10 步、进度条拖拽、1x/2x/4x 变速
- 标题页 **▶ 回放上一局** 可重温最近一战（存于 localStorage，超容量时自动跳过持久化）

## AI 代打

顶栏 🤖 按钮随时开关：开启后你的回合（出牌、弃牌、要闪/桃/无懈响应、八卦/贯石斧选择）全部由 AI 自动决策，适合挂机观战；再次点击立即切回手动。阵亡观战状态下按钮自动失效。

## 调试参数

- `index.html?screen=hero` 直达选将
- `index.html?screen=story&role=fan` 直达剧情（指定身份）
- `index.html?screen=game&hero=lvbu&role=nei` 指定武将身份直接开局
- `index.html?autotest=1` 全 AI 自动对局（极速、无特效）
- `index.html?uitest=1` UI 冒烟测试：真实 DOM 点击模拟玩家完整操作

## 规则要点（与常见同类玩法的对齐）

- 距离按**存活者**环形计算，阵亡者不占位
- 八卦阵：无论是否手握闪，被杀时都可以选择赌判定（三选一弹窗）
- 无懈可击支持**嵌套**：无懈可以再被无懈反制，效果逐层反转
- 杀的响应面板会标明来源、伤害预判（酒杀 +1）与无双提示
- 判定牌（乐不思蜀/闪电/八卦）会在舞台中央停留展示后再入弃牌堆
- 战绩自动记录在 localStorage，标题页显示累计局数与胜场

## 测试

`test/run-tests.js` 在 Node 中直接驱动游戏引擎跑完整对局（stub 掉 DOM/特效），校验每局无异常、正常分出胜负、全场 89 张牌数守恒（每回合边界断言）：

```bash
node test/run-tests.js 30        # 跑 30 局
node test/run-tests.js 5 42     # 5 局，指定随机种子（可复现）
```

近期结果：30/30 通过，胜方分布 主公方 11 / 反贼 11 / 内奸 8，三方均可获胜。

## 目录结构

```
sanguo-kill/
├── index.html          # 页面骨架（标题/选将/剧情/对局/结算 五屏）
├── css/style.css       # 全部视觉：羊皮纸+朱砂+鎏金、卡牌、特效动画
├── docs/
│   └── card-art-prompts.md  # 全部卡牌/武将的文生图 Prompt 手册（含 Mermaid 图表）
├── js/
│   ├── data.js         # 卡牌/武将/身份/剧情数据 + 牌库构建
│   ├── fx.js           # 视觉特效 + Web Audio 合成音效 + 卡牌 HTML
│   ├── ai.js           # AI 决策：身份推理/敌意评估/出牌策略
│   ├── ui.js           # 渲染 + 玩家交互（选牌/选目标/响应面板/弹窗）
│   ├── engine.js       # 引擎：回合流程/结算/濒死/胜负
│   └── main.js         # 入口：屏幕流转/选将/剧情/自动测试
└── test/run-tests.js   # 无头逻辑回归测试
```
